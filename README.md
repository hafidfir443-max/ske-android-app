# Sinar Kencana Elektronik — Aplikasi Android (Flutter WebView)

Aplikasi Android berbasis **Flutter + WebView (`webview_flutter`)** yang terhubung langsung ke sistem web **Sinar Kencana Elektronik** (`https://ske.wuaze.com/`).

## Cara Build `.apk` Otomatis (GitHub Actions)
1. Push repository ini ke branch `main`.
2. Buka tab **Actions** di GitHub repository ini.
3. Tunggu workflow **Build Flutter APK** selesai (±2–5 menit).
4. Download file APK pada bagian **Artifacts** (`SinarKencanaElektronik-APK`).
